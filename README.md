# GestureTab

一款专为 macOS 打造的 **AltTab 风格多任务网格视图 + 触控板四指手势切窗工具**。

针对 macOS 原生触控板“三/四指左右滑只能切全屏应用、非全屏窗口切换不便”的痛点，让你在**完整保留系统「三指拖移（拖动窗口/选文字/拖文件）」**的同时，用**四指滑动**像翻卡片一样在所有窗口之间快速切换。

---

## 核心功能与亮点

- **零冲突保留系统「三指拖移」**
  - 默认使用 **四指滑动** 触发与选窗，完全不干扰你的三指拖移习惯。
  - 菜单栏内也提供备选的「三指竖向/倾斜姿态切换（实验性）」模式。
- **双视图显示模式（无滚动自适应排版）**
  - **紧凑悬浮面板**：居中毛玻璃卡片网格展示所有窗口，自动根据窗口数量等比缩放卡片大小，3 行以上也能一屏完整显示，**禁止滚动**；当前选中窗口带 **蓝色高亮边框**。
  - **全屏调度视图**：仿 macOS 调度中心铺满全屏的深色毛玻璃大图预览 + 底部 App 图标徽章，视野更大更清晰。
  - 呼出时按最近使用顺序（MRU）排列，并默认高亮上一个使用的窗口，轻滑即切。
- **全范围窗口覆盖**
  - 同时纳入 **当前桌面窗口、全屏应用窗口、Dock 最小化窗口、其他桌面（Space）窗口**（卡片右上角标注 `全屏` / `最小化` / `其他桌面`）。
  - 结合 `SkyLight`、`ScreenCaptureKit` 与本地磁盘缓存（`~/Library/Caches/GestureTab/thumbs/`），切过的桌面和窗口均可保留预览缩略图。
- **稳重顺手的触控板操控**
  - **二维步进 + 速度甩动加成**：慢滑精准逐格选窗，稍微滑快可自动跨 2~3 格（配合震动反馈）；行末右滑可顺延到下一行首（行首左滑回上一行末），左上角首项、末尾项及最上/最下行边界均不回卷循环。
  - **物理边缘 10% 兜底连选**：在触控板中间区域停住手指时选框绝对静止；仅在滑到触控板最外圈 10% 物理边缘并按住时才继续沿该方向连续推进，反向轻拉即刻停住。
  - **手势期间防背景误滚动**：自动拦截四指滑动期间底层窗口的滚动（`scrollWheel`）与误拖拽事件。
  - **松手立即切入 / `Esc` 取消**：手指离开触控板立刻聚焦目标窗口（含自动恢复最小化窗口、精准前置同软件多窗口）；按 `Esc` 随时取消。

## 下载与使用方式

### 方式一：直接下载仓库中的 `GestureTab.app` 使用

1. 点击 GitHub 页面右上角 **Code → Download ZIP**（或 `git clone https://github.com/jianxiaomiao/GestureTab.git`）。
2. 解压后将 `GestureTab.app` 拖入「应用程序（`/Applications`）」文件夹并双击打开。
3. **⚠️ 首次打开若提示“无法验证开发者”或“已损坏”**：
   由于本开源软件未使用付费 Apple Developer 证书公证，从浏览器下载会被 macOS 加上隔离属性（Quarantine）。在「终端」执行一次以下命令即可正常打开：
   ```bash
   xattr -cr /Applications/GestureTab.app
   ```
   或在「系统设置 → 隐私与安全性」底部点击「仍要打开」。

### 方式二：本机源码编译并配置固定签名（推荐，更新不掉权限）

> 编译环境只需系统自带或命令行工具（运行 `xcode-select --install` 即可，无需完整 Xcode）。

```bash
git clone https://github.com/jianxiaomiao/GestureTab.git
cd GestureTab

# 可选（强烈推荐）：在本机登录钥匙串生成自签名代码签名证书，此后更新重编不再重授系统权限
./setup_signing.sh

# 编译生成通用架构（Intel + Apple Silicon）GestureTab.app
./build_app.sh
```

## 首次使用配置（必看 3 步）

启动 `GestureTab` 后，屏幕顶部菜单栏会出现多窗口网格图标：

1. **授予「辅助功能」权限（必选）**
   前往 **系统设置 → 隐私与安全性 → 辅助功能**，开启 `GestureTab`。
   *作用：读取跨桌面/最小化窗口、精准切换前置指定窗口、拦截手势期间的底层滚动事件。*
2. **授予「屏幕录制」权限（推荐）**
   前往 **系统设置 → 隐私与安全性 → 屏幕录制**，开启 `GestureTab`。
   *作用：抓取各窗口的实时与缓存缩略图（若不开启仍可切窗口，卡片将显示 App 图标）。*
3. **避免系统原生四指手势冲突（关键）**
   前往 **系统设置 → 触控板 → 更多手势**：
   - 将 **「在全屏幕应用之间轻扫」** 改为关闭（或改为其他手势，GestureTab 网格本身已能直接切换所有全屏与其他桌面窗口）。
   - 建议同步关闭或调整四指 **「调度中心」**，避免与四指手势同时触发。

## 日常操作说明

- **呼出与选窗**：
  - **触控板四指呼出**：四指轻放在触控板上向任意方向轻滑即可弹出多任务网格；保持手指在触控板上**上下左右滑动**移动蓝色高亮框。
  - **键盘 `Option + Tab` 呼出（持久打开视图）**：外接鼠标或单手打字时可按 `Option + Tab`（`Option + Shift + Tab` 反向）呼出持久面板，配合方向键 / `Tab` / 触控板 / 鼠标选窗。
- **连续步进**：如果窗口很多、手指滑到触控板边缘或已推开起点较远，**保持手指按住不松**，选框会自动沿该方向连续逐格前进。
- **切入窗口**：
  - 触控板呼出（默认）：**松开手指**即刻切入；若在菜单栏开启「触控板呼出后保持持久停留」，则松手不切，等待确认。
  - 持久打开模式下：按 **`Enter`（回车）**、**`Space`（空格）** 或 **鼠标点击卡片** 进入选中窗口。
- **快捷操作（`Q` / `M` / `Esc`）**：
  - 按 **`Q`** 键：执行 **关闭当前选中窗口** 或 **退出选中窗口所属程序**（可在菜单栏自由切换，支持其他桌面窗口）。
  - 按 **`M`** 键：一键 **最小化或恢复** 当前选中窗口。
  - 按 **`Esc`** 键：直接关闭面板不切换。
- **菜单栏调节项**：点击顶部菜单栏图标可随时调整：
  - 视图显示模式（紧凑悬浮面板 / 全屏调度视图）、手势触发模式
  - 触控板滑动灵敏度、网格每行列数（5 / 6 / 7 列）
  - **忽略应用名单**：一键勾选隐藏不希望出现在网格里的软件
  - 选中窗口按 `Q` 键操作、`Option + Tab` 呼出开关、触控板持久停留开关
  - 触控板震动反馈开关、物理边缘 10% 自动连选开关、速度甩动加成开关
  - **开机自动启动**开关（自动同步 `GestureTab.app` 所在路径，并带单实例防重保护）

## 系统要求与已知边界

- **系统要求**：**macOS 14.0 (Sonoma) 及以上**（支持 Intel `x86_64` 与 Apple Silicon `arm64` 通用二进制）。
- **关于未访问过桌面的缩略图**：受 macOS WindowServer 底层机制限制，如果某个其他桌面或已最小化的窗口自本次开机/打开后从未切换过去渲染过，系统尚未生成其图像缓冲，此时卡片会显示 App 图标占位；只要切换过去看一眼被缓存下来，之后切换走或重启软件都会持久保留该窗口缩略图。
